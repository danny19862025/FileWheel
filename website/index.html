Effortless Workflow

From file manager to finished output in one gesture

01

Drag to the floating target

Grab one or many files from Dolphin, Nautilus, or Windows File Explorer and drag them onto the floating orange target at the right edge of your screen.

02

Glide onto a rounded wedge

The radial wheel blooms immediately with only the valid operations for your file family. Tap Shift (Convert), Ctrl (Tools), or Alt (Actions) mid-drag.

03

Release — saved beside the original

Jobs run asynchronously in the background with real progress and cancellation. Existing filenames automatically get a safe numeric suffix (_2, _3).

Native Desktop Integration

One Rust + GTK4 codebase, tailored for both desktops

🐧

Linux (Wayland & X11)

Tested on KDE Wayland · Flatpak · Nix Flake · Source
  • Wayland layer-shell: Floating drop target and radial wheel use gtk4-layer-shell, with automatic regular GTK window fallback on other compositors.
  • Tray & background mode: System tray opens the main window or toggles the target; filewheel --background starts target-only.
  • Desktop-aware audio & theme: Follows XDG Desktop Portal theme changes and desktop event-audio volume via optional libcanberra.
  • Zero global hijacking: Respects Wayland security boundaries — no global Shift-drag interception, no forced file associations.
🪟

Windows 10 & 11 (x86_64)

Inno Setup Installer · Portable ZIP · Win32 Native Shell
  • Always-on-top edge target: Native Win32 tool-window styling keeps the orange drop target accessible without cluttering your taskbar.
  • Tray & optional sign-in launch: Close to tray, right-click for Show/Hide target or Quit, with optional startup toggle in the installer.
  • No admin rights needed: Installs cleanly into %LOCALAPPDATA%\Programs\FileWheel or runs completely unregistered from the Portable ZIP.
  • Automatic engine discovery: Finds winget-installed engines on PATH or default folders — built-in tar.exe handles ZIP/TAR/GZIP out of the box.
Engineered for Trust

Built in Rust with strict safety & zero shell injection

🛡️

Zero Shell Invocation

Core conversion jobs invoke executable paths with explicit argument arrays — filenames with quotes, spaces, or shell punctuation never touch a shell.

📁

Private Staging & Safe Naming

Jobs stage inside private temporary folders, reserve collision-safe output names (_2, _3) without overwriting originals, and clean up failed/cancelled runs.

⚡

Process-Group Cancellation

Cancelling a job, hitting a timeout, or quitting mid-run terminates the converter's entire process group (Win32 Job Objects / Unix PGIDs), including child wrappers.

🔒

Privacy-First Diagnostics

Local logs record only operation, paths, and outcome — clipboard contents, document text, and converter stderr are never written. Zero telemetry.

🧪

Real-File Verification Suite

Backed by cargo test, formats_test.py, --self-test, --smoke-test (real GTK drops & theme regressions), and --sound-test.

🧩

Clean Modular Layout

engine.rs (capabilities & jobs) · wheel.rs (radial geometry & hit-testing) · layer.rs (Wayland FFI) · appearance.rs · main.rs.

Get Started

Install FileWheel on Windows or Linux

1. Download Installer or Portable ZIP

No admin rights needed. Installs per-user into %LOCALAPPDATA%\Programs\FileWheel.

Download FileWheel-Setup-x86_64.exe ↗ Portable ZIP

Verify SHA-256 with Get-FileHash .\FileWheel-Setup-x86_64.exe -Algorithm SHA256.

2. Optional Conversion Engines (PowerShell / winget) 
winget install -e --id ImageMagick.ImageMagick
winget install -e --id Gyan.FFmpeg
winget install -e --id TheDocumentFoundation.LibreOffice
winget install -e --id oschwartz10612.Poppler
winget install -e --id Python.Python.3.13
winget install -e --id QPDF.QPDF

Prebuilt x86_64 Flatpak Test Release

No compilation required. Download FileWheel-full-test-x86_64.flatpak and its .sha256 file to ~/Downloads.

Download Flatpak Release ↗
Verify, install & run 
cd ~/Downloads && sha256sum -c FileWheel-full-test-x86_64.flatpak.sha256
flatpak remote-add --user --if-not-exists flathub https://flathub.org/repo/flathub.flatpakrepo
flatpak install --user flathub org.gnome.Platform//51
flatpak install --user ~/Downloads/FileWheel-full-test-x86_64.flatpak
flatpak run --user --branch=full-test io.github.danny19862025.FileWheel
Arch / CachyOS / EndeavourOS Dependencies 
sudo pacman -Syu --needed base-devel git rust gtk4 gtk4-layer-shell \
  desktop-file-utils xdg-utils imagemagick ffmpeg libreoffice-fresh \
  poppler libarchive python coreutils qpdf ttf-dejavu

Ubuntu 26.04+, Debian 13+, Fedora & immutable distros are in docs/INSTALL.md.

Clone & user-local install (no sudo) 
git clone https://github.com/danny19862025/FileWheel.git
cd FileWheel
bash install.sh
"$HOME/.local/bin/filewheel"

Installs to ~/.local/bin/filewheel plus launcher & icon.
